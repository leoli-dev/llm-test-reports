# 档案设计

[English](design.md) | [简体中文](design_CN.md)

主要任务是找到过去的实验并阅读实际证据。界面采用安静的实验档案风格：冷蓝导航栏、白色报告纸面与克制的字体层级。重点视觉是模型实际做出的两款游戏截图。

- 配色：墨色 #183447、深蓝 #194f76、青绿 #186f6a、背景 #f4f7fa、纸面 #ffffff、分隔线 #dce5ec。
- 字体：本机 Avenir Next／系统无衬线字体及中文系统回退，不请求远程字体。等宽字体用于报告代码。
- 布局：持续可见的左侧导航、两项作品、可搜索的实验表，以及带报告选择器和标题目录的阅读视图。
- 交互：稳定 hash 链接，独立的文字／引擎／推理位置筛选，空结果提示，Markdown 下载与 GitHub 原文链接。窄屏中表格在报告内部滚动。
- 语言：英文入口 `index.html`，中文入口 `index_CN.html`；切换时保留当前报告和筛选。Markdown 和目录文件按 `_CN` 配对。
- 环境：首页显示有日期的本机配置参考，报告区分当前系统与实验时系统，并注明客户端／推理主机角色。
- 视觉克制：不使用自动入场动画、装饰性指标面板或生成背景图。截图作为历史实验的证据保留。
