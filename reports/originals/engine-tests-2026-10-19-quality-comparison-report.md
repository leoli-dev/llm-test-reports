## OFF main-group speed and memory

Each cell is the median of recorded requests in the category, including quality failures and truncations; counts vary as the experiment progresses. Output length affects speed, so output tokens and request duration must be considered together. Metal/MLX values are fresh-process allocator high-water marks with different backend definitions. RSS, footprint and global GPU counters are stored separately. All use unified memory and must not be added together.

**The backends' prefill rates use different timing definitions.** MLTF measures from native request start to the first TokensEvent, including work before the first speculative output. VLM derives prompt_ms from BatchGenerator prompt_tps. Neither is full HTTP TTFT, and their table ratio does not directly establish a pure GPU prefill speedup. Common client TTFT and total request time are measured separately.

MLTF decode runs from the first native output to Done, with the first output batch subtracted from the numerator. VLM's rate uses server first/last output records and tokens excluding the first batch; predicted_ms is then inferred from total output/rate rather than directly measuring an identically defined phase. **Answers in this quality round are short, so the first speculative block and shutdown overhead have a large effect. Decode tok/s varies substantially and cannot replace the 4,096-token long-output stability test.** CSV files retain per-question output lengths, rate ranges, timing definitions and raw fields. Short outputs are neither padded nor forced to suppress EOS.

client N/span=total output tokens divided by the interval between the client's first and last receipt of generated content. It includes the first output batch and may overestimate speed for short outputs; it is retained alongside backend rates as a diagnostic. **At the same processed input length of 126,976 tokens, client time to first output and total request duration are the more directly comparable latency measures in this round**, but answer length and correctness must still be considered together.
