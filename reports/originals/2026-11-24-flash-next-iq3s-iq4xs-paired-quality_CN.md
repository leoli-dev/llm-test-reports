## 方案与证据

- Claude Opus 5.5 经 Orca 审核协议。24 对独立试跑只以合并耗时和截断数量决定正式规模与预算。正式题目在生成前固定，按难度和年份筛选，排除函数式题面、交互题、多解和浮点容差题。从固定版 LiveCodeBench Lite 选 Python 3 stdin 题，保留入选题的全部私有用例。公开例不计入主判分。每 40 题交替使用 IQ3→IQ4、IQ4→IQ3。 [固定数据版本](https://huggingface.co/datasets/livecodebench/code_generation_lite/tree/0fe84c3912ea0c4d4a78037083943e8f0c4dd505) · [LiveCodeBench](https://github.com/LiveCodeBench/LiveCodeBench)
- 本机推理与客户端均在 MacBook Pro Mac17,6 / Apple M5 Max / CPU 18 / GPU 40 / 128 GiB / arm64。实验时系统为 macOS 27.2.1（26B131）。Splash 1.7.0，源码 `61f6d51643a2cf8b3ed868dcb4bcda176ae578ec`。ISTA GSQ-RCO IQ3_S revision `ed59f92082b1e93c0e96d60a8b11aab089b52f09`，Unsloth UD-IQ4_XS revision `f5d175de2cf7f720d45d6064019a81fcf056e986`。两包的词表和模板一致（模板 SHA-256 前缀 `12827f24b742ea4e`），校准与混合量化配方不同。
- 同一 262144 上下文、96 GiB 上限、INT8 KV、FP32 state、SSD 缓存关闭、DFlash2，温度 1、top_p .95、top_k 20。主测每题一次 medium，thinking 4096，总输出 8192，同题同 seed、请求独立 cache salt，一次仅一请求。启动前停止原服务，切包后确认 API 模型并丢弃预热。动态推测解码下，seed 不能保证逐 token 重现。首次预检用错了 API ID 核对字段，停机回滚后修正，预检没有生成回答。
- 判题用断网的 arm64 Python 3.13 Docker，镜像 ID `sha256:9ef1a599f863231c3d91e941389bfdc4a2d6070557243d54df1a4e57015b960e`。对 stdout 按空白切 token 比较，题面明确允许时忽略大小写。容器限制 384 MiB、候选进程地址空间 320 MiB，每用例 4 CPU 秒、7 秒进程看门狗，超时或进程被杀以原代码补判两次取多数。截断、空答案或缺代码块、运行错误和错误输出计失败。基础设施退出单列。95% 区间采用配对多项式约束得分法，优势需要 95% 区间排除零且点估计至少 5 个百分点。90% 区间全落入 ±5 个百分点为实践等效，上界低于 +5 个百分点支持 IQ3 非劣。 [Tango 配对得分法](https://pubmed.ncbi.nlm.nih.gov/9595618/)
- 48 个工具用例来自 12 个模板，每模板含原题及三个参数变体。长文表中的档位是原题库的标签，实际输入 token 在证据里。三仓各单次，最多 40 次工具调用和 24,000 输出 token，公开 unittest 可从工具调用，隐藏套件在生成后跑。辅助诊断用于辨认故障类型，各行样本小或共用模板。生成前修复了工具题 messages 与空调用字段的兼容性，主测条目与判分原协议无变动。
- [逐题脱敏结果与采样、判分状态](../../assets/2026-11-24-flash-next-iq3s-iq4xs-paired-quality/paired-results.json)。档案不含语料、模型输出源码、私有端点与凭据。

## 与既有结果怎么读

此前同版本短探针对 IQ4_XS 测得峰值多 8.68 GiB、原生解码慢 3.3%，首事件早 0.241 秒。本轮端到端速率含生成与输入处理时间。 [CAP-05 同版本短探针](./2026-11-24-flash-next-iq4xs-splash-cap05-replay_CN.md)

Strata 对 Q8_0 的测量中 IQ4_XS 平均 KL 为 0.101、IQ3_S 为 0.144，测试文本 PPL 分别为 4.120 和 4.097。双 3090 的同协议 456 道 MMLU 结果为 IQ4_XS 86.40%、IQ3_S 加 Q8 PLE 86.62%。两项资料分别测输出分布保真度与通识考试。 [Strata 量化测量](https://github.com/Niko1221/Strata/blob/main/docs/QUANTS.md) · [双 3090 实测](https://github.com/Niko1221/Strata/issues/5881)

ITLab 在同版 Strata 上对 Unsloth UD-IQ4_XS V3.1 和 Swift 1.5 abliterated IQ3_S 跑了 49 项。两边编程均 34/34、软件项目均 83/83。对方用 Swift 改版，且两边 top_p 不同。ISTA 另报告原版 IQ3_S 在 SWE-bench Verified 为 82.0%，底模 82.8%。论坛直接比较有相反的日常使用体验，公开材料仍缺这两个原版发布包的同条件逐题代码评测。 [ITLab 49 项测试](https://itlab.cl/en/unsloth-avalon-iq3-ks-itlab-bench-ranking/) · [ISTA 发布方讨论](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF/discussions/26) · [社区使用记录](https://www.reddit.com/r/LocalLLM/comments/1xtnw7y/qwen_38_fn_gsq_rco_iq3s_is_better_than_new/)

这批竞赛题可能出现在预训练数据中。单次采样、题库几乎全部为 AtCoder、过滤掉巨型用例与多解题、采用本地 Python 判题时间限制，都会影响可外推的范围。两臂使用不同厂商发布配方，结果只支持评价实测的两个模型包与本机设置。
